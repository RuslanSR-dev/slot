# Стратегия тестирования, версия 0

Документ живой: каждая итерация добавляет в него уровень или правило.

## Уровни тестов

Определения заданы через границу, а не через название. Большая часть споров про «unit против integration» — это споры о разных определениях.

| Уровень | Что запущено | Что заменено | Где лежит | Статус |
|---|---|---|---|---|
| unit | Код сервиса в процессе теста | Сеть, база, время | `tests/unit` | есть |
| component | Один сервис + его настоящая база в контейнере | Соседние сервисы и внешние API — заглушки | `tests/component` | итерация 1–2 |
| contract | Ожидания потребителя против схемы поставщика | Всё остальное | `tests/contract` | итерация 2 |
| smoke | Весь стек из `compose.yaml` | Только внешние системы | `tests/smoke` | есть |

e2e через интерфейс — только критические сценарии, единицы штук. Всё, что можно проверить уровнем ниже, проверяется уровнем ниже.

## Quality gates в пайплайне

| Gate | Порог | Зачем |
|---|---|---|
| Форматирование и линтер (ruff, включая правила безопасности `S`) | 0 нарушений | Ревью человека — про смысл, а не про стиль |
| Строгая типизация (mypy strict) | 0 ошибок | Детерминированная проверка AI-кода до запуска |
| Unit-тесты | все зелёные | — |
| Покрытие | не ниже 90%, только растёт | Храповик, а не цель |
| Предупреждения в тестах | считаются ошибками | Устаревшие вызовы ловим в день появления |
| Smoke на эфемерном стеке | все зелёные, версия сборки совпадает | Образ собирается, стартует и это именно он |
| Время задач CI | 5 и 10 минут | ADR-0004 |

## Правила

1. Никаких `sleep` в тестах: ждём условие с таймаутом.
2. Повторный запуск упавшего теста — это сигнал для учёта flaky, а не способ получить зелёную сборку.
3. Тест не «лечится» автоматически. Любое изменение ожиданий теста проходит ревью человеком.
4. Порог можно ослабить только через ADR.
5. Smoke-тесты знают только URL. Тот же файл потом проверяет развёрнутый стенд.

## Что сознательно отложено

Производительность, сканеры безопасности, трассировка — итерация 6. Mutation testing — после появления доменной логики в итерации 1: на `/health` мутировать нечего.
