# ADR-0001. Фиксируем архитектурные решения в ADR

Статус: принято · 2026-09-19

## Контекст

Проект — тренажёр архитектора. Ценность в нём не код, а решения и их обоснование. Через месяц никто не вспомнит, почему выбрана эта очередь или этот уровень тестов.

## Решение

Каждое решение, которое дорого отменить, записываем в `docs/adr/NNNN-название.md`: контекст, решение, последствия, отвергнутые альтернативы. Одна страница. Статусы: предложено → принято → заменено (со ссылкой на новый ADR). Принятый ADR не переписываем, а заменяем новым.

## Последствия

- Плюс: решения можно оспорить по существу, а не по памяти. ADR — готовый материал для резюме и интервью.
- Цена: 15–20 минут на решение.

## Альтернативы

- Вики или чат: теряются и не проходят ревью вместе с кодом.
