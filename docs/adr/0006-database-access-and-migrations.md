# ADR-0006. Доступ к базе и миграции: SQLAlchemy 2 + Alembic, component-тесты на Testcontainers

Статус: принято · 2026-09-19

## Контекст

У сервиса `booking` появляется Postgres. Нужно выбрать, как код работает с базой, как меняется схема и как это тестировать на настоящей базе, а не на подмене.

## Решение

1. Доступ к базе — SQLAlchemy 2 в синхронном режиме, драйвер psycopg 3. Асинхронность не используем: для учебного проекта она добавляет сложность без новой пользы.
2. Схема меняется только миграциями Alembic. Миграции лежат внутри пакета сервиса (`booking/migrations`), поэтому одинаково запускаются из тестов и из образа.
3. Миграции применяет отдельный одноразовый контейнер `booking-migrate`. Сервис стартует только после его успешного завершения. Сам сервис миграции не запускает: при нескольких копиях сервиса они бы запускали их одновременно.
4. Уровень component: сервис и настоящий Postgres того же образа, что и в стеке, поднятый Testcontainers. Между тестами таблицы очищаются.
5. Порог покрытия считается по unit и component вместе, в задаче `component`. Задача `checks` остаётся быстрой и гоняет unit без порога. Порог не снижен (90%), но измеряется на большем наборе тестов.
6. Бюджет новой задачи CI `component` — 8 минут (по правилам ADR-0004).

## Последствия

- Плюс: Alembic умеет сравнить схему после миграций с моделями в коде. Тест на это ловит забытую миграцию. Условия частичных индексов Alembic не сравнивает — для индекса из ADR-0005 есть отдельный тест.
- Плюс: component-тесты работают с тем же Postgres, что и прод; поведение индексов, транзакций и ошибок не подделано.
- Цена: component-тесты требуют Docker и работают медленнее unit.
- Цена: для локальной работы через Colima Makefile сам находит сокет Docker. На GitHub это не нужно.

## Альтернативы

- Чистый SQL через psycopg и миграции SQL-файлами: прозрачнее, но проверку «схема совпадает с кодом» пришлось бы писать самим.
- База в памяти (SQLite) для тестов: быстрее, но другой диалект, другие индексы и другое поведение при конкуренции — тест на гонку на ней ничего бы не доказал.
- Миграции при старте сервиса: проще, но небезопасно при нескольких копиях.
